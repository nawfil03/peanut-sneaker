# 👟 Peanut Sneakers — E-commerce Front-end

A front-end website for **Peanut Sneakers**, an online sneaker store, with a shop page plus **login** and **registration** pages.

---

## ✨ Features

- Home page with navigation (Home, Shop, Register, Login, Gallery)
- Brand sections – Nike, Adidas, Kobe, Converse, Under Armour
- Product cards with original price, sale price and discount badges
- Login and Registration pages with form layouts
- Responsive layout

## 📄 Pages

| Page | File |
|---|---|
| Home / Shop | `peanut/main.html` |
| Login | `peanut/Login.html` |
| Register | `peanut/Register.html` |

## 🛠️ Tech stack

HTML5 · CSS3 · Bootstrap · jQuery · Font Awesome

## 🚀 How to use

No install or build step is needed.

```bash
git clone https://github.com/nawfil03/peanut-sneaker.git
cd peanut-sneaker
```

Open **`peanut/main.html`** in your browser, or serve the folder locally:

```bash
npx serve .
# or
python -m http.server 8000
```

Then visit http://localhost:8000 and open `peanut/main.html`.
